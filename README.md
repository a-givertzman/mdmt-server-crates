## Что нужно поправить при переходе с 0.1.0

1. Чтение из контекста теперь возвращает `Option`.
   `ctx.read()` и `ctx.read_ref()` больше не паникуют на отсутствующем
   значении — его нужно обработать:
2. `Properties::properties()` теперь возвращает `Result<Vec<(String, JsonVal)>, Error>`
   вместо `Vec<(String, String)>`. Значение — готовый JSON, а не строка с JSON.
   Если раньше результат писался в БД через `serde_json::to_string`, двойное
   кодирование нужно убрать.
3. Трейты `ContextRead`, `ContextReadRef`, `Properties` объявляются
   в приложении. Их сигнатуры должны совпадать с макросами.

## context-macros

### ContextAccess
- `read` — чтение по значению и по ссылке, возвращает `Option`;
- `read_ref` — только чтение по ссылке, без требования `Clone`;
- `write` — запись, без изменений;
- `skip` — поле исключается из генерации;
- `skip_load` — поле не загружается из снимка.
Флаги можно перечислять в любом порядке.
Опечатка или повтор флага — ошибка компиляции.

### ContextProperties
- сериализует значение в JSON без паники, возвращает Result<Vec<(String, JsonVal)>>;
- `#[iec_id = "..."]` проверяется: один, непустой, строковый.

### ContextLoad
- `with_snapshot` сохраняет прежнее поведение частичной загрузки;
- некорректное применение derive даёт ошибку компиляции, а не panic;
- дубли ключей (во входных данных и между полями) не применяются
  и попадают в отчёт об ошибках;
- `unused_in_db` отсортирован, `is_clean()` — только про ошибки;
- `skip_load` полностью исключает поле, включая требования к типу.

### Общее
- `#[context(...)]` можно использовать нескольким макросам на одном поле:
  незнакомые флаги игнорируются.

## cgraph-macros

`#[eval_depend]` переписан.
- Понимает код в том виде, как он написан: UFCS-вызовы, `ctx.read()`,
  `read_ref()`, `write()`, а также цепочки `?`, `ok_or`, `unwrap`, `as_ref`.
- Тип зависимости берётся из кода: из типа переменной или из записываемого
  значения.
- Списки inputs/outputs детерминированы.
- Запрещает передавать транзакцию во вспомогательные методы.
- Исправлена сборка: не хватало feature syn.

## context-ui-macros — новый крейт

### UiContextAccess
- генерирует `ui_read` / `ui_write` на `RawContext`;
- `iec_id` разбирается как `<префикс контекста>.<поле>`;
- поле можно исключить флагом `ui_skip`.

### UiContextProperties
- генерирует `UiProperties` для элемента контекста;
- имя поля принимается в PascalCase и snake_case;
- Option-поле отдаёт Null и очищается записью Null.

## event-opcode

Без изменений.
